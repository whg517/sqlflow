# SQLFlow 全量 QA 任务清单

- 日期：2026-08-13
- 对象：`http://localhost:8090`（admin/admin123，PostgreSQL 平台库）
- 方法：Playwright headless Chromium（浏览器级）+ curl（API 级）黑盒验证
- 范围：三角色主流程 + 高危回归 + 已知 partial 领域
- 基线：项目当前为 L0 内部验证级，文档明确预期存在缺陷

## 验证方法约定

- **B** = 浏览器级（Playwright 导航/点击/读 DOM/截图）
- **A** = API 级（curl 直打端点，验响应码与 body）
- 每个任务记录：实际结果 / 与预期偏差 / 严重度（Blocker / High / Medium / Low / Pass）

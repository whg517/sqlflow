# SQL 模板使用说明

SQL 模板用于复用带值参数的查询。模板中的参数不会被直接拼接到 SQL，而是在服务端转换为数据库驱动参数并单独绑定。

## 创建模板

在“SQL 模板”页面创建模板，使用以下占位符：

```sql
SELECT id, name
FROM users
WHERE team_id = {{team_id}}
  AND status = {{status:active}}
```

- `{{team_id}}` 是必填参数。
- `{{status:active}}` 的默认值是 `active`。
- 占位符用于值，不用于表名、列名或 SQL 关键字。
- 模板可设为私有或公开；私有模板只有所有者可以读取和渲染。

## 在查询工作台使用

可以直接在查询工作台顶部点击“使用模板”，搜索并选择模板，填写参数后点击“生成查询”。系统会创建新的参数化查询标签，并自动选择同类型的可用数据源。

也可以从“SQL 模板”页面进入：

1. 点击模板行的“渲染模板”。
2. 填写必填参数并点击“渲染”。
3. MySQL/PostgreSQL 的 `SELECT` 或 `WITH` 模板会显示“在查询中使用”。
4. 进入查询工作台后选择数据库并执行。

工作台会显示模板来源和绑定参数数量。执行、MySQL EXPLAIN、CSV/JSON 导出及查询历史恢复都会保留参数绑定。手动修改 SQL 会立即解除旧绑定，此后需要直接编辑 SQL 或重新从模板渲染。

## 当前边界

- MySQL 使用 `?`，PostgreSQL 使用 `$1`、`$2` 等参数标记。
- MongoDB 模板当前支持渲染预览和复制，不直接进入查询工作台。
- DDL/DML 模板只支持预览和复制，变更操作仍须通过工单提交。
- 单次查询最多 100 个参数；参数仅支持字符串、数字、布尔值和 `null`，单个字符串最大 64KB。
